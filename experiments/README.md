# Experiment artifact index

**Historical-material notice (2026-10-04):** the existing experiment plans,
runbooks, audits, and result bundles in this directory describe the earlier
Service-evolution/co-evolution or Customer-policy experiments. They are
preserved as research history, but are not the active protocol and must not be
run with the current runtime. The current method is documented in
[`../docs/CUSTOMER_ADVERSARIAL_SEARCH.md`](../docs/CUSTOMER_ADVERSARIAL_SEARCH.md).

The active method is free-text Customer strategy search against fixed Service
S0, scored only by the official task-success outcome on runtime-valid episodes.
There is currently no active formal/pilot runbook in this folder. To reproduce
an older result, check out the Git commit associated with that result rather
than attempting to load it through current code.

The historical items remain useful for understanding prior decisions and
results, including the old pilot/formal plans, freeze manifests, forensic
audits, and Seed 7 trace excerpts. Their presence does not imply that old
co-evolution code or old schemas remain supported.
